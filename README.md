# Wildlife Protection & Poaching Detection System

## Description
The Wildlife Protection & Poaching Detection System is an advanced computer vision application designed to safeguard wildlife by detecting poaching activities and analyzing animal behavior patterns. Leveraging the YOLOv8 object detection model and an LSTM-based behavior analysis module, this system processes video footage to identify animals, poachers, and potential threats in real-time.

### Key Features
- **Object Detection**: Identifies and tracks animals, poachers, and related objects using YOLOv8.
- **Behavior Analysis**: Detects unusual animal movements and distress signals using an LSTM model.
- **Threat Assessment**: Evaluates poaching likelihood and provides actionable insights (Low, Moderate, High).
- **User Interface**: Built with Streamlit, offering an intuitive interface to upload videos, view processed results, and download analysis.

### Technologies
- **YOLOv8**: For robust object detection.
- **LSTM**: For behavior prediction.
- **Streamlit**: For the interactive web interface.
- **OpenCV**: For video processing.
- **Python**: Core programming language.
